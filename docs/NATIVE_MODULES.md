# Todo list with a Turbo Native Module

Menu → **Todo list (Turbo Native Module)**. The todos live in native code:
Kotlin on Android, Objective-C++ on iOS. JavaScript only shows them.

## The pieces

| File | What it is |
| --- | --- |
| `specs/NativeTodos.ts` | The contract. A TypeScript `Spec` interface that Codegen reads. |
| `package.json` → `codegenConfig` | Tells Codegen where the specs are (`specs/`) and what to generate (`AppSpecs`). |
| `android/.../NativeTodosModule.kt` | Android implementation: extends the generated `NativeTodosSpec` and saves to SharedPreferences. |
| `android/.../NativeTodosPackage.kt` | Registers the module; added in `MainApplication.kt`. |
| `ios/ReactNativeExamples/RCTNativeTodos.h/.mm` | iOS implementation: conforms to the generated `NativeTodosSpec` protocol and saves to NSUserDefaults. |
| `src/screens/todo/native/todoNativeStore.ts` | JS store: calls the module and keeps a log of every call. |
| `src/screens/todo/native/TodoNativeScreen.tsx` | The screen: add, search, edit, toggle, delete, and the call log. |

## How a call travels

```
JS: NativeTodos.add('Milk', 1759708800000, false)
  → JSI (no JSON bridge): a C++ host object generated by Codegen
  → Kotlin NativeTodosModule.add(...)   /   Obj-C++ -[RCTNativeTodos add:...]
  → SharedPreferences / NSUserDefaults
  ← resolves the Promise with { id: '3', text: 'Milk', ... }
```

- **Async methods** (`getAll`, `search`, `add`, `update`, `remove`, `clear`)
  return a Promise and don't block the JS thread.
- **Sync methods** (`count`, `getInfo`) return the value directly. JSI makes
  this possible; keep them fast because JS waits for them.
- Errors: native code rejects with a code (`E_NOT_FOUND`, `E_EMPTY_TEXT`)
  that JS reads as `error.code`.

## Building

Native code changes need a new build. Reloading Metro is not enough.

```powershell
# Android (Codegen runs as part of the Gradle build)
npm run android
```

```sh
# iOS, on a Mac (Codegen runs during pod install)
cd ios && pod install && cd ..
npm run ios
```

If the screen says **Native module not found**, the app on the device was
built before the native code existed: rebuild it.

## Changing the module

1. Change `specs/NativeTodos.ts`.
2. Rebuild. The generated `NativeTodosSpec` changes, so the Kotlin and
   Objective-C++ classes no longer compile until they match the new spec.
3. Update `NativeTodosModule.kt` and `RCTNativeTodos.mm`, and the Jest fake in
   `__mocks__/nativeTodosFake.ts`.

Generated code, to read but not edit:

- Android: `android/app/build/generated/source/codegen/`
- iOS: `ios/build/generated/ios/AppSpecs/`

## Debugging

- Android logs: `adb logcat -s NativeTodos` (search results are logged).
- iOS logs: Xcode console, lines starting with `[NativeTodos]`.
- Stored data on Android:
  `adb shell run-as com.reactnativeexamples cat shared_prefs/native_todos.xml`
- Each native call is also a Sentry span (`op: native.call`).

# Bridging screen (NativeBridgeDemo)

Menu → **Bridging (JS ⇄ native)**. A second Turbo Native Module,
`specs/NativeBridgeDemo.ts`, with one method per way of crossing between
JS and native:

| Spec | Kotlin | Objective-C++ | What it shows |
| --- | --- | --- | --- |
| `currentThread(): string`, `add()` | returns the value | returns the value | Sync call on the JS thread |
| `asyncThread(): Promise<string>`, `addAsync()` | `promise.resolve(…)` | `resolve(…)` | Async call on a native thread |
| `withCallback(value, callback)` | `callback.invoke(…)` | `callback(@[…])` | Callback (called once) |
| `readonly onTick: EventEmitter<TickEvent>` | `emitOnTick(map)` | `[self emitOnTick:@{…}]` | Events native → JS |
| `echo(value: UnsafeObject)` | `ReadableMap` → `WritableMap` | `NSDictionary` | Type conversion |
| `fail(code, message): Promise<void>` | `promise.reject(code, message)` | `reject(code, message, nil)` | Errors with a code |

Files: `NativeBridgeDemoModule.kt`, `NativeBridgeDemoPackage.kt` (registered in
`MainApplication.kt`), `ios/ReactNativeExamples/RCTNativeBridgeDemo.h/.mm`
(inherits `NativeBridgeDemoSpecBase` to get `emitOnTick:`), and the screen in
`src/screens/bridging/`.

Events: JS subscribes with `NativeBridgeDemo.onTick(handler)` and must call
`subscription.remove()` when the screen closes. The native timer is stopped in
`invalidate()` when the JS runtime reloads.
